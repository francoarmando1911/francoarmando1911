### 💼 About Me

Técnico Universitario en Programación (UTN FRCU) trabajando como **Software Developer** en **GASNEA**, donde mantengo y evoluciono una plataforma interna construida sobre **Oracle APEX**. Me enfoco en diseño de bases de datos, resolución de incidentes en producción y optimización de procesos críticos de negocio. Fuera del trabajo, desarrollo aplicaciones full stack modernas con el ecosistema de JavaScript/TypeScript.

- 🔧 Mantenimiento evolutivo y correctivo de aplicaciones Oracle APEX
- 🗃️ Diseño y optimización de objetos de base de datos (PL/SQL, SQL)
- 🐞 Resolución de incidentes de producción y soporte técnico interno
- 🌐 Desarrollo full stack con Next.js, Node.js y MongoDB
- 📱 Aplicaciones móviles con React Native / Expo
